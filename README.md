# OB対談 進行アプリ（NoFAKE）

高校サッカーOBの対談（NoFAKE）の収録で使う、iPad用の進行アプリです。
司会なしで、テーマ・タイマー・お題を進めます。進行の記録と、動画編集用の画像（テーマ・お題のカード）を書き出せます。

- 使い方：このページを iPad の Safari で開き、「共有」→「ホーム画面に追加」。一度開けば、通信なしでも動きます
- 中身：テーマと、お題の一覧だけです。撮影した映像や、出演者の個人情報は入っていません
- 記録・画像は、iPadの中にだけ保存されます（この場所には送られません）
